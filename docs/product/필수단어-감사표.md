# 필수 단어 감사표 — 상황 고정어 vs 모호어

작성 2026-10-15. 대상 `efc8690` + `062e045`(팀 main) · `agent_contract/categories/*.json` 원문 대조.
목적: 2차 테스트(10/18–21)에서 **관찰만** 하고, 10/22 동결 해제 뒤 **한 변경**으로 목록을 고치기 위한 기록.

---

## 1. 방법 — 두 신호를 섞지 않는다

| 신호 | 답하는 질문 | 출처 |
|---|---|---|
| **CEFR 등급** | "이 단어를 학습자가 이미 아는가?" (교과서에 언제 나오는가) | CEFR-J Wordlist 1.6 |
| **상황 고정성** | "이 단어가 그 상황의 **이름**인가?" | 계약 파일의 `required_keywords` 대조 |

**핵심**: A1은 "쉽다"가 아니라 **"일찍 배운다"** 는 뜻이다. 등급이 낮다고 나쁜 키워드가 아니고, 높다고 좋은 키워드가 아니다.
문제는 **등급이 아니라 넓은 뜻**이다 — `check`는 확인·계산서·무늬, `stop`은 멈추다·정류장, `keep`은 유지·보관·맡기다.

**검증기 동작(실측)**: `validators.py`의 `check_weak_coverage`가 `k in s["en"].lower()` — **부분문자열**. 키워드 **하나만** 걸려도 통과한다. 그래서
구체적 단어 옆에 모호어를 **나란히** 두면, 모호어만으로 통과한다. 이것이 "추가 요청" 상황에서 `another`가 통과하는 경로다.

**등급으로 못 재는 것**: `one more`, `check in`, `check out`, `connecting flight`은 **구(句)** 라서 CEFR-J 표제어 조회가 **원리적으로 안 된다**(전부 "목록 밖"으로 나옴). 이 4개는 등급 열을 비워 둔다.

## 3. CEFR-J의 한계 — 실측으로 확인

여행 현장어가 **목록에 없다**: `allergy`, `refill`, `boarding`, `delayed`, `cancelled`, `wi-fi`, `connecting flight` — 전부 조회 결과 "목록 밖"(6절 재현 명령).
반대로 모호어는 전부 **A1 대역**이다: `check` A1, `keep` A1, `store` A1, `stop` A1, `another` A1, `noise` A1, `pay` A1, `breakfast` A1, `towel` A1, `water` A1.

**결론**: CEFR-J는 **모호어를 찾는 데만** 쓴다. 여행 현장어를 찾는 데는 쓰지 못한다. 두 방향을 섞으면 이 표가 무의미해진다.

목록 밖 단어는 **오류가 아니다** — 교과서 코퍼스의 범위 밖일 뿐이다(`delayed`가 목록에 없는데도 계약 키워드인 것이 그 증거).

## 4. 2차 테스트(10/18–21) 관찰 시트

목록은 **바꾸지 않는다**(설계 문서 47행: 2차 사용자 테스트 전 적용 금지). 바꾸면 테스트가 바뀐 목록을 재게 되고, 개선 근거가 사라진다.

기록할 것 — 위 네 상황에서 **모호어만 있는 문장이 나왔는가**:

| 상황 | 볼 것 | 실제 문장 | 모호어 단독? |
|---|---|---|---|
| `request_side` | `another`만 있는 문장 | | ☐ |
| `leave_luggage` | `keep`/`store`만 있는 문장 | | ☐ |
| `ask_platform` | `stop`만 있는 문장 | | ☐ |
| `pay_check` | `check`가 `checkout`에 걸린 문장 | | ☐ |

추가 기록: 사용자가 그 문장을 **이해 못 했는지**, 또는 **상황과 무관하다고 느꼈는지**. 이게 목록 교체의 실제 근거다.

## 5. `required_keywords.patch`(8,897 B)와의 관계

그 패치는 **빈 situation에 키워드를 추가**한다(`upgrade`, `wifi`, `noise`, `room service`, `not working`).
`check`·`another`·`keep`·`store`·`stop`은 **그대로 둔다.**

| 항목 | 방향 | 판단 |
|---|---|---|
| 빈 situation 17개 채우기 | 커버리지 확대 | 10/22 이후 별건 |
| 네 줄 교체(2절) | **모호어 제거** | "양질의 단어" 요구에 직접 대응 |
| 단어 경계 수정 | 합성어 오탐·미탐 | 네 줄 교체와 **한 변경**으로 묶는다 |

셋은 목적이 다르다. 10/22 이전에는 코드를 바꾸지 않는다. 그 사이 0줄 작업은 4절 관찰이다.

`check_weak_coverage`는 키워드 목록이 비어 있으면 내용 검사를 건너뛴다(`validators.py` 233–234행, `if kws:`). 상황 id만 맞는 문장이면 `Hello there.`도 통과하고, 문장이 없을 때만 `weak_not_covered`다. 17칸은 생성을 실패시키지 않는다. 취약 상황으로 넘어왔을 때 내용 검사가 없을 뿐이다.

그래서 10/22 이후 첫 변경은 **네 줄에서 모호어를 빼고 단어 경계를 넣는 것**이다. 근거는 등급이 아니라 상황 고정성이다. `suitcase`가 `luggage`보다 쉽고 `cloakroom`은 목록 밖이라, 등급으로 대체어를 고르지 않는다. 17칸을 채우는 패치는 그 다음 별건이다. 그 패치는 모호어 네 줄을 그대로 둔다.

## 6. 재현 명령과 미확인

계약 원문(상황 30개 중 13개에 키워드, 17개는 키 없음):

```bash
python3 -c "
import json,glob,os
for p in sorted(glob.glob('agent_contract/categories/*.json')):
    d=json.load(open(p,encoding='utf-8')); print('---',os.path.basename(p))
    for s in d.get('situations',[]):
        print(' ',s.get('situation_id'), s.get('required_keywords'))
"
```

등급 조회(CEFR-J 1.6 `A1~B2` 시트, 첫 열을 표제어로):

```python
# ALL 시트 6,864 표제어 · 품사 행 7,801 · 출판 페이지 6,868 / 7,801
# ALL_sep 시트까지 합치면 7,208 — 이전에 7,208을 "표제어 수"로 잘못 읽은 값
```

### 미확인 / 한계

- **연습 문장 수**: **50 = 공통 30 + 장소 템플릿 20** 이 정본이다. 데모 문장 1개는 그 50 밖이다. 30+20+1은 51이라, 50에 데모를 더한 식으로 적지 않는다. 정규식 추출은 `en:` 문자열을 세어 64/76이 나왔고, 장소 이름과 목업 여행 기록(`tr_*`)이 섞여 쓰지 않는다. 커버리지 %(이전 83%, 86% 주장)는 이 표에서 빼 둔다.
- **빈 키워드 17개**: 내용 검사를 건너뛴다. 2026-10-15에 17개 상황 모두, 문장 `Hello there.`는 이슈가 없고 문장 0개는 `weak_not_covered`인 것을 실행으로 확인했다.
- CEFR-J는 일본 학교급 기준이다. 한국 학습자 재보정은 하지 않았다 → 등급은 **상대 비교용**으로만.
- OEWN 2025의 두 단어 표제어(`boarding pass` 06703392-n, `check in` 00968184-v)는 **다른 세션 확인**이며 이 작업에서 재검증하지 않았다.
- 목록 밖 여행어(`allergy`·`refill`·`wi-fi`)에 등급을 줄 대안 사전은 아직 없다. OEWN은 뜻을 주고 등급을 주지 않는다.
